# Third-party notices

This project is a greenfield ETL foundation and intentionally avoids copying or redistributing third-party code without explicit review.

## Current status

This repository currently contains original code and a documented project skeleton. Any future third-party dependency must be reviewed before being added.

## Planned review before release

- Python package licenses
- Qt / PySide6 licensing terms
- database driver licensing terms
- REST and object-storage client licensing
- Spark / Kafka integration licensing if adopted
- any Talend-derived materials used only under explicit compliance review

## Responsibility

All contributors must keep track of dependency origins and ensure compatibility with project licensing requirements.
